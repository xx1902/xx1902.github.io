# 网站图标

首页、Paper、Study 和兼容跳转页统一使用 `favicon-chestnut.png`，即候选 B：带刺外壳与笑脸的栗子图标。

- 来源：https://www.flaticon.com/free-icon/chestnut_3507269
- 原始图片：https://cdn-icons-png.flaticon.com/512/3507/3507269.png
- 规格：512 × 512，PNG；本地保存，网页不依赖外部图片服务。
- 图标地址附带 `?v=chestnut-b-2`，让浏览器重新请求图标；替换图片后可更新版本参数以避免沿用旧缓存。
- 使用与发布需遵守素材来源页的授权和署名要求。

`favicon.png` 为原胡萝卜，`favicon.svg` 为上一版李子，保留归档，当前页面均不引用。
